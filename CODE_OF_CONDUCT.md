# Code of conduct

This project adopts the [Contributor Covenant][cc], version 2.1. The full text
is at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

The short version: be decent. Assume good faith, take criticism of your code as
criticism of your code, and leave harassment, personal attacks and other
people's private information out of it.

This applies in issues, pull requests, commit messages, and anywhere else the
project is being discussed.

## Enforcement

Report anything that needs attention to the maintainer, privately, through the
address on their GitHub profile. Reports are handled confidentially. Responses
run from a warning to a permanent ban, in proportion to what happened.

[cc]: https://www.contributor-covenant.org/
